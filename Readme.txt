
  Siemens Pie - программа для генерации бланка ТУ по файлам конфигурации терминалов Siemens.
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

  Программа представляет собой консольную утилиту, написанную на Python.
  Для работы программе требуются два файла: XML и XRio.
  Эти файлы необходимо получить из DEX файла конфигурации с помощью DIGSI (4.93, с 4.94 не работает!).
  Из DIGSI Manager делаем экспорт устройства, выбираем сначала XML, затем XRio.
  Имена файлов лучше оставлять одинаковыми. При этом будут экспортированны файлы со ВТОРИЧНЫМИ
  значениями уставок.
  Программа (файл sp.exe) принимает на вход в качестве параметров имена XML и XRio файла, можно
  указать только один файл, второй будет найден по имени, если он лежит в той же директории с
  тем же именем.

  Для удобной работы с программой нужно запустить sp.exe - при этом будет зарегистрирован
  обработчик файлов с расширением .xrio, т.е. при открытии этих файлов будет запускаться
  SiemensPie и рядом создан Excel файл экспорта конфигурации из конфига (шаблон ТУ).

  Настройки процессинга хранятся в config.json

  Помимо уставок программа формирует матрицу ранжирования.
